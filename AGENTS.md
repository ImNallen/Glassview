# Working in this repository

## Layout

npm workspace with one package: `apps/desktop` (Tauri + Svelte desktop app). Brand
assets live in `assets/brand` and are generated by `scripts/generate-brand-assets.py`.

Root scripts forward to the workspace: `npm run desktop <script>`. `npm run check`,
`npm test`, and `npm run build` run across all workspaces. Rust checks use
`--manifest-path apps/desktop/src-tauri/Cargo.toml`.
